# Personal Live V1 threat model

Status: **OFFLINE PERSONAL LIVE V1 ENABLEMENT READY; EXTERNAL ACTIVATION BLOCKED.** R2A–R2D, versioned R1A source authority, fictional Lever R1B, source-to-R2 queue wiring, and the target-independent synthetic runner framework are implemented. Calibration remains `UNCALIBRATED`. R1 source-enabled Beta remains `WAITING_FOR_APPROVED_TENANT`; real target operation remains `TARGET_APPROVAL_REQUIRED`. No real source, form, upload, submission, or hosted exposure is approved. This is not penetration-test certification. The product is single-owner and loopback-only.

R2A treats every vacancy byte as inert data: parsing cannot dereference a URL, invoke AI/tools, modify policy, activate a tenant, or create an application action. Source pointers are observation-bound, range-checked, and SHA-256 verified; state and modality are independent; same-proposition conflicts stay linked rather than silently resolved; empty or unbounded evidence does not claim complete coverage; legacy placeholder provenance is explicitly unavailable; current corruption is explicitly invalid; and owner corrections create a new version with explicit correction linkage.

The immutable schema-v2-to-v3 migration and additive v3-to-v4 R2 migration were rehearsed with fictional backup/restore. Versioned R2 evaluation, duplicate, queue, correction, calibration, and event-specific audit records fail closed on stale or malformed bindings. The confirmed private command requires an exact token, ignored/untracked paths, current schema/integrity/FK checks, and a freshly verified backup before evaluation. Historical and current rows, downstream staleness, privacy, and aggregate-only reporting were verified. Every source and real-runner boundary remains closed.

Implemented Beta mitigations include loopback Host/Origin validation, an HttpOnly SameSite=Strict local session, expiring one-use action/session-bound nonces, private output realpath/create-new confinement, semantic verified-claim validation, measured PDF fitting and PDF/DOCX parity, exact capability-gated source readers, immutable version/audit records, consistent verified SQLite backup/restore, synthetic stop/replay/frozen-review coverage, and repeatable tracked/all-ref/build-artifact/private-canary auditing. These controls support manual-intake Beta only; they do not activate a source or real runner.

Public assets: source, fictional fixtures, safe documentation and CI. Private local assets: profile/version snapshots, SQLite/WAL/backups, real vacancies/URLs, answers/notes, CVs/letters, browser sessions and receipts. External boundaries: source APIs/pages, employer forms and optional future providers. Candidate data must not cross a boundary because an ad contains a URL or instruction.

Threat actors include malicious files/sites/ads, cross-origin websites targeting loopback, compromised dependencies/accounts, accidental publication, other local users and malware. Likelihood is qualitative L/M/H before planned mitigation. Residual risk assumes tests pass; missing controls remain open blockers.

## Mandatory gates

R2 fixes truth/verification/provenance defects before trusted ranking. R3 enforces all-field claim/layout/path guards. R5 requires local-origin/session controls, approved session key storage, disclosure/destination restrictions and final-action tests before real filling. R8 requires zero unresolved critical/high exposure or irreversible-action defects, current dependency review, backup/restore drill and build/privacy audit. R10 needs a separate internet-facing authentication/authorisation/pairing/retention/residency design and independent security review.

These are defensive requirements, not claimed exploits. No live external target or unrelated local service was attacked. If sensitive publication is found, stop pushes/releases, report only paths/commits privately, preserve evidence and ask the owner about remediation. Credential revocation, visibility reversal, history rewrite and private-data deletion need appropriate separate authority; public copies cannot be recalled.
