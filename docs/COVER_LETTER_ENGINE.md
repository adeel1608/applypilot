# Cover Letter Engine

Phase 0/1 provides a deterministic foundation, not advanced rewriting. The generator uses the normalized employer and role title, references actual listed requirements, and selects only matching verified candidate skills. Every candidate-specific sentence has profile fact references and the result always requires human review.

If no verified relevant skill is available, the generator uses a neutral invitation to discuss relevant verified background; it does not invent evidence. Missing profile support is omitted. Forbidden claims remain forbidden even when a job advert strongly suggests them.

Future Phase 11 work should add truth validation equivalent to the resume engine, configurable Australian letter layouts, tone controls, PDF validation, requirement prioritization, and adversarial claim tests. Optional AI wording may be layered only after redaction, provenance, consent, and deterministic fallback design.
